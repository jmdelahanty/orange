# Empty-background v1 fixtures

Documents for `orange.empty_background_capture` v1 (`capture_*`) and the
start-snapshot block `orange_recording_empty_background_v1` (`snapshot_*`),
both referencing `orange.image_levels.v1`. Everything under `valid/` must
validate and everything under `invalid/` must fail, in jsonschema and in the
generated C++ parser alike. Digests and statistics are illustrative, not
computed from an image. Shared with Palette through agent-contracts
`orange-palette/empty_background_v1/`.
